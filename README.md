# 📝 React Todo List App

A dynamic and responsive Todo List application built with **React.js** and **Material-UI (MUI)**. This project allows users to efficiently manage their daily tasks with persistent local storage.

## ✨ Features

* **Add Tasks:** Quickly insert new tasks to your list.
* **Toggle Status:** Mark tasks as completed or active.
* **Task Filtering:** Filter tasks based on their status (All, Completed, Active).
* **Local Storage Persistence:** Tasks are saved in the browser's `localStorage` so data isn't lost on page refresh.
* **Responsive UI:** Clean interface built with Material-UI components.

## 🛠️ Tech Stack

* **Frontend Framework:** React.js
* **UI Components:** Material-UI (MUI)
* **Build Tool:** Vite / Create React App
* **State Management:** React Hooks (`useState`, `useEffect`, `createContext`)
